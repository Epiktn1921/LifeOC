# Life OS

Веб-планер, где в одном месте собраны календарь, задачи, цели и финансы: главная страница из ярких карточек, тёмная тема и боковое меню. Регистрация по электронной почте, данные синхронизируются между телефоном и компьютером.

Весь сайт — один файл `index.html`. Регистрация работает через бесплатный сервис [Supabase](https://supabase.com).

## Что умеет

- **Фирменные фишки**: плашки-папки, как на логотипе; оценка дня из задач, спорта, еды, воды и трат, серия удачных дней и итоги недели; конфетти и звук, когда выполнены все задачи, достигнута цель или закрыта недельная норма тренировок; главную можно перестроить (перетащить, скрыть плашки) и выбрать акцентный цвет.
- **Обзор**: главная страница из карточек: сегодняшний день, ближайшая встреча, задачи на сегодня, остаток бюджета, цели, платежи, расписание и загрузка недели.
- **Календарь**: виды «День», «Неделя», «Месяц», «Год» и «Список». Свои календари с любым цветом, повторы, напоминания, свайп для перелистывания. Нажмите на время в дне, чтобы добавить событие.
- **Задачи**: списки как в «Напоминаниях», разделы «Сегодня», «Запланировано», «С флажком», повторяющиеся задачи. Быстрый ввод обычным текстом: `Купить молоко завтра 18:00 #Покупки !`
- **Цели**: по шагам или числовые («Накопить 300 000 ₽»), кольцо прогресса, срок появляется в календаре.
- **Финансы**: бюджет на месяц, расходы по категориям, доходы, регулярные платежи. Платежи видны в календаре, кнопка «Оплатить» записывает расход.
- **Спорт**: график веса с целью, тренировки за неделю, история, таймер (секундомер, обратный отсчёт, интервалы вроде табаты).
- **Еда**: калории за день по приёмам пищи, калькулятор (вес порции × калорийность на 100 г, белки, жиры, углеводы), запоминание продуктов, вода, график за 7 дней, расчёт дневной нормы.
- **Профиль**: календари, списки, категории, тема, смена пароля, выход и удаление аккаунта.

## 1. Выложить сайт на GitHub Pages

1. На github.com нажмите **New repository**. Название, например, `life-os`, тип **Public**, затем **Create repository**.
2. Нажмите **uploading an existing file**, перетащите все файлы и нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/life-os/`.

Сайт работает сразу: регистрация по почте и паролю уже есть. Но без шага 2 аккаунт и данные хранятся только в браузере, где человек зарегистрировался, а забытый пароль восстановить нельзя. После шага 2 аккаунт работает на любом устройстве, а пароль восстанавливается через письмо.

## 2. Включить регистрацию (Supabase, бесплатно)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и нажмите **New project**. Придумайте название и пароль базы, выберите ближайший регион и нажмите **Create new project**. Подождите пару минут.
2. Откройте **SQL Editor → New query**, вставьте всё из `supabase.sql` и нажмите **Run**. Должно появиться «Success».
3. Откройте **Authentication → URL Configuration**:
   - **Site URL**: адрес сайта, например `https://ВАШ_ЛОГИН.github.io/life-os/`
   - **Redirect URLs**: добавьте этот же адрес.
   Тогда ссылки из писем (подтверждение почты, новый пароль) будут вести на ваш сайт.
4. Откройте **Project Settings → API** (или кнопку **Connect**) и скопируйте **Project URL** и ключ **anon public** (может называться **publishable**).
5. Откройте на GitHub файл `index.html`, нажмите карандаш и найдите в начале скрипта блок `CONFIG`. Вставьте значения и нажмите **Commit changes**:

   ```js
   const CONFIG={
     SUPABASE_URL:'https://abcdefgh.supabase.co',
     SUPABASE_KEY:'eyJhbGciOi...'
   };
   ```

Через минуту на сайте появятся «Регистрация» и «Вход», восстановление и смена пароля.

### Про ключи

- Ключ **anon / publishable** можно хранить в коде. Правила из `supabase.sql` не дают читать чужие данные.
- Ключ **service_role / secret** никогда не вставляйте в `index.html` и не выкладывайте на GitHub.

### Письма

Supabase сам отправляет письма для подтверждения почты, но бесплатно их всего несколько в час. Если пользователей станет много:
- подключите свою почту в **Authentication → Emails → SMTP Settings**, или
- отключите подтверждение в **Authentication → Sign In / Providers → Email → Confirm email** (вход сразу после регистрации, но адрес не проверяется).

## На телефоне как приложение

Откройте сайт в Safari, нажмите «Поделиться» → **На экран «Домой»**. Life OS откроется во весь экран, как обычное приложение.



## Клавиши на компьютере

`←` `→` листать, `T` сегодня, `N` новая запись, `/` поиск, `Esc` закрыть окно.
